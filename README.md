# iQube

Study notes, synced automatically from my Obsidian vault.

## Sync

This repo is pushed automatically whenever a note changes. A `launchd` agent
watches the folder with `fswatch` and commits + pushes within a few seconds.
Commits titled `Auto-sync ...` are machine-generated.
